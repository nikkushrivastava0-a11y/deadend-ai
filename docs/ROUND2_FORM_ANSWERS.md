## Changes from Round 1
We narrowed the MVP to one dependable public GitHub discussion-to-handover path rather than a broad enterprise integration ecosystem. Instead of the initially suggested Next.js, Supabase and OpenAI Agents SDK stack, we used a dependency-free Node server and vanilla frontend to make review and evidence reliable in the build window. Actual Three.js WebGL now renders the evidence constellation; the user receives a functional source-to-approval workflow with honest limitations. No private organisational data was needed.
