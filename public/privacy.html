DeadEnd/Privacy
DATA & TRANSPARENCY

Evidence first. Privacy clearly stated.

DeadEnd's live demonstration is intended only for public GitHub discussions or synthetic and explicitly authorised project notes.

What the demo processes

Imported text, source URLs and review decisions are used to reconstruct candidate technical decisions. Public GitHub requests are made to the GitHub REST API.

Storage and session limits

The hosted demonstration stores encrypted, expiring workspace state in the browser session. This is not authenticated organisational storage, and tab/session cleanup can remove the workspace. Do not enter passwords, personal secrets or confidential company data.

Third-party services

Vercel hosts the app; GitHub provides publicly accessible source discussions. Live model-based extraction is not configured in production.

Questions or source concerns
