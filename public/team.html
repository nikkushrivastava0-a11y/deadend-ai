Try a team handover in five steps

Start by creating your own account below.

  1. Create an account with a unique handle and a saved password.
  2. Create a workspace as owner, then choose Load fictional Stripe case.
  3. Invite a reviewer and a recipient. Copy each code. Use a separate browser profile or private window for another account; two normal tabs share the same sign-in. Separate private tabs may also share a session.
  4. Review the Stripe finding, record a recheck or resolve a disagreement, then approve it again.
  5. Issue a handover as owner. The recipient refreshes, downloads and acknowledges it.

Roles are enforced by the server. All sample evidence is fictional. For real work, import only public or authorised notes.
